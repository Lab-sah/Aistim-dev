Tidak mencakup logika tiap userscript (lihat [2026-11-06-userscripts.md](2026-11-06-userscripts.md)) dan tidak diuji di browser.

## Metode dan pengujian

- Salinan bersih `origin/main` diambil dengan `git archive` ke folder terpisah, supaya working tree tidak tersentuh.
- Manifest dibaca langsung dengan Python (`json`).
- Pola kode (`eval`, `new Function`, `document.write`, `createElement('script')`, `innerHTML`, `postMessage`, `console.`) dihitung dengan pencarian teks di `background/`, `content/`, dan `popup/`.
- Build Web Store dijalankan dari salinan itu: `python3 tools/build-store.py <folder-keluaran>`. ZIP yang dihasilkan dibuka dengan `zipfile` untuk memeriksa manifest dan `content/content.js`.
- Pengecekan sintaks semua script di `scripts/` memakai JavaScriptCore (`jsc`), karena `node` tidak tersedia di mesin ini. Lookbehind regex diganti sementara untuk pengecekan, karena parser `jsc` di mesin ini tidak mendukungnya. Ini hanya pengecekan sintaks, bukan pengujian perilaku.
- Konfigurasi branch protection `main` diambil dengan `gh api repos/devtim-lab/Aistim-dev/branches/main/protection`.
- Data uji buatan: tidak ada. Tidak ada pengujian di browser.
- Cara mengulang: jalankan perintah build dan pencarian pola di atas dari commit yang sama.
