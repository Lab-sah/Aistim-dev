- [x] `console.*` mencetak ID produk dan gudang, nama gudang, objek galat, dan alasan teknis. Baris 2012 mencetak respons JSON simpan rak. Isinya status dan pesan dari Erzap, bukan kredensial.

- Temuan 1, 4, 6, 11: rekam satu sesi di Erzap asli, misalnya lewat `scripts/rekam.js` atau DevTools, lalu catat:
  - daftar autocomplete `#barcode_barang` untuk barcode yang menjadi awalan barcode lain;
  - teks respons `aktifitas_stok` di sekitar "Penempatan Rak";
  - respons `detail_stok` untuk produk di akun multi-outlet;
