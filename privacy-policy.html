Kebijakan Privasi Aistim Tool

Berlaku untuk ekstensi Aistim Tool (Chrome, Edge, dan browser berbasis Chromium). Terakhir diperbarui: 4 November 2026.

1. Ringkasan

Aistim Tool adalah ekstensi browser yang menjalankan script bantu di halaman ERZAP (*.erzap.com) dan CRM Aistim (*.aistim.icu). Ekstensi ini tidak mengumpulkan, menjual, atau membagikan data pribadi Anda ke server pengembang. Semua pengaturan disimpan di browser Anda sendiri.

2. Data yang disimpan di perangkat Anda

Ekstensi menyimpan data berikut di penyimpanan lokal browser (chrome.storage.local). Data ini tidak dikirim ke pengembang:

DataUntuk apa
Daftar script dan status aktif/nonaktifMenampilkan dan menyimpan pilihan Anda di popup.
Salinan kode script dan ETag dari GitHubSupaya script tidak diunduh ulang setiap menit, dan tetap berjalan saat offline.
Daftar file dan daftar hapusMengetahui script mana yang harus dijalankan atau dihapus.
Waktu dan hasil sinkronisasi terakhirDitampilkan di popup.
Waktu pemeriksaan versi ekstensi terbaruAgar pemeriksaan tidak berulang terlalu sering.

Script yang Anda jalankan di halaman ERZAP atau CRM dapat menyimpan data sendiri di browser (misalnya di sessionStorage) untuk kebutuhan halaman itu. Data tersebut tetap berada di browser Anda.

3. Data yang tidak kami kumpulkan

  • Nama, alamat email, nomor telepon, atau identitas lain yang dikumpulkan ekstensi untuk pengembang.
  • Kata sandi, token, atau cookie ERZAP. Ekstensi tidak membacanya untuk dikirim ke mana pun.
  • Riwayat penjelajahan di luar halaman ERZAP dan CRM Aistim.
  • Data analitik atau pelacakan. Ekstensi tidak memuat layanan analitik.

4. Koneksi jaringan yang dilakukan ekstensi

Ekstensi melakukan permintaan jaringan berikut:

Ekstensi tidak membawa data pribadi Anda dalam permintaan ke layanan pengembang selain yang Anda kirim sendiri lewat halaman tersebut.

5. Fitur rekam (devtool)

Script devtool (rekam.js) tidak aktif secara default. Fitur ini hanya menyala jika Anda membuka halaman ERZAP dengan parameter ?rekam=1, dan dimatikan dengan ?rekam=0.

Saat aktif, fitur ini mencatat klik dan permintaan jaringan di halaman ERZAP untuk membantu analisis masalah. Token, cookie, dan kolom kata sandi disamarkan atau tidak ikut dicatat. Hasil rekaman hanya disalin ke clipboard oleh Anda sendiri. Ekstensi tidak mengirimkannya secara otomatis ke pengembang. Anda yang memutuskan apakah akan membagikannya, dan sebelum membagikan, periksa isinya terlebih dahulu.

7. Kode script dari luar paket

Ekstensi mengambil kode script dari repositori GitHub proyek ini dan menjalankannya di halaman yang cocok. Kode itu dapat berubah tanpa rilis ulang ekstensi. Script yang dijalankan dapat dilihat di repositori, dan dapat dinonaktifkan satu per satu dari popup.

8. Berbagi data dengan pihak lain

Kami tidak menjual, menyewakan, atau membagikan data pengguna kepada pihak ketiga untuk tujuan iklan atau pelacakan. Layanan yang menerima permintaan jaringan di poin 4 (GitHub, situs ERZAP, partdistro.com, dan situs CRM) memproses permintaan itu menurut kebijakan mereka sendiri.

9. Anak-anak

Ekstensi ini ditujukan untuk pengguna dewasa yang bekerja di ERZAP. Kami tidak sengaja mengumpulkan data dari anak di bawah 13 tahun.

10. Menghapus data

Anda dapat menghapus semua data ekstensi dengan menghapus Aistim Tool dari chrome://extensions, atau menghapus data situs ERZAP dan CRM dari pengaturan browser.

11. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal "terakhir diperbarui" di atas akan diganti dan versi terbaru akan dipublikasikan di halaman ini.
